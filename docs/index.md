# DMC Lite Shield Manual

Welcome to the customer manual for the **DMC Lite Shield** – a motion control I/O shield designed for the Arduino Giga R1, specifically for use with Dragonframe stop-motion animation software.

![DMC Lite Shield](https://www.dmclite.com/image.jpg){ width="600" }

## About the DMC Lite Shield

The DMC Lite Shield is a professional motion control interface that provides:

- **Multiple Driver Control**: Buffered and reinforced step and direction signals to up to 8 drivers
- **RJ45 Output**: Use RJ45 cables wired exactly like the DMC-32
- **DB37 Output**: Alternative DB37 output for legacy hardware designed for Kuper
- **Arduino Giga Native**: Designed to mount perfectly and communicate seamlessly with the Arduino Giga
- **Camera Control**: Camera meter and shutter control via 2.5mm audio jack
- **E-Stop**: Optically isolated e-stop output
