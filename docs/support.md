# Support

For board, ordering or service questions, use the contact information supplied with your order or visit [dmclite.com](https://www.dmclite.com). Warranty, returns and repair terms are those confirmed by your seller; this manual does not establish them.

For a documentation error, [open an issue](https://github.com/leepeffer/dmc-lite-shield-docs/issues). Include the page and proposed correction. Do not post private order details in a public issue.

## Useful information to send

- Board revision and clear photographs of the board and wiring.
- Dragonframe version, operating system and GIGA firmware source/configuration.
- External driver model, motor supply and affected channel.
- What you commanded, what happened, LED behavior and any error message.
- Tests already performed, with power and wiring conditions noted.

Stop powering damaged equipment until the cause has been checked. See [troubleshooting](troubleshooting.md) and [driver replacement](hardware/driver-replacement.md).

For software and camera help, use [Dragonframe support](https://www.dragonframe.com/support/). For the host board, use [Arduino GIGA documentation](https://docs.arduino.cc/hardware/giga-r1-wifi/).
