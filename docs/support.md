### Before Contacting Support

To help support assist you quickly, please have the following information ready:

**Hardware Information**:

- DMC Lite Shield version (if known)
- Arduino Giga model and revision
- Motor drivers being used (make and model)
- Motors being used (specifications)
- Computer operating system

**Software Information**:

- Dragonframe version
- Arduino IDE version (if relevant)
- Firmware version (if known)

**Problem Description**:

- What were you trying to do?
- What happened instead?
- What have you already tried?
- Any error messages (exact text or screenshots)
- When did the issue start?
