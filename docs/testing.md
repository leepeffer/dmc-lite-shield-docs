# V2 board test checklist

Work through the checks in order. **Pass** means tested successfully; **Fail** means an issue needs attention. Leave unavailable tests unchecked and explain in notes. Repeat for each board.

!!! warning "Confirm V2 wiring first"
    RJ45 pins **2 and 6 are active negative outputs**, not V1 grounds. Do not connect old cables until wiring is confirmed. These are not Ethernet ports. See [V2 pinouts](hardware/wiring.md), [firmware setup](setup/firmware.md) and [E-stop setup](setup/estop.md).
